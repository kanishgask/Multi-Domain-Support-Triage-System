# Multi-Domain Support Triage System

## 📌 Overview
An AI-based ticket classification system that automatically categorizes and prioritizes support tickets.

## 🚀 Features
- Automatic ticket classification
- Priority detection
- Admin dashboard
- REST API backend
- Scalable architecture

## 🛠 Tech Stack
Frontend: React  
Backend: Node.js + Express  
API: REST  

## ⚙️ Installation

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start
